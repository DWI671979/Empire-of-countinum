# Empire of Continuum

A collaborative open-source fictional world platform built with Streamlit.

## Features

- User Registration
- User Login
- Creator Profiles
- Collaborative Worldbuilding
- Story Publishing
- Artwork Galleries
- Canon Wiki
- Timeline Management
- Copyright Center
- Moderator Dashboard

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
